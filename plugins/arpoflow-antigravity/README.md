# ArpoFlow para Google Antigravity

Crie e edite sites e aplicativos TanStack Start na sua conta ArpoFlow. Você pode visualizar uma prévia privada, verificar o projeto e publicar a versão escolhida.

## Instalação

Extraia o ZIP do plugin. No diretório que contém a pasta `arpoflow` extraída, execute os comandos abaixo.

```sh
agy plugin install ./arpoflow
agy plugin list
```

No Antigravity, abra **Customizations → Installed → ArpoFlow → MCP Servers** e escolha **Authenticate**. No CLI, abra `/plugin`, expanda **ArpoFlow** em **Installed** e escolha **Sign in**. Autorize o acesso à conta ArpoFlow pelo navegador.

## Abrir uma prévia

Peça “Liste os meus projetos no ArpoFlow”. Em seguida, envie “Crie um projeto de teste chamado Agenda de oficinas, salve uma página com esse título e mostre o link clicável da prévia exatamente como o ArpoFlow retornou. Informe o ID do projeto, a versão e a validade da prévia. Mantenha o projeto como rascunho.” Aprove as ações solicitadas pelo Antigravity.

O link concede acesso à prévia enquanto estiver válido. Se ele expirar, peça outro link para a versão salva.

Em outra conversa, informe o ID ou o nome do projeto e peça para ler a versão atual antes de editar. Depois, peça a prévia da nova versão salva. Abra o **Resumo** no painel para conferir o rascunho e a versão no ar. Em **Publicar**, você escolhe a versão desejada. Se precisar voltar à publicação anterior, use **Histórico → Publicações do site**. [Projetos no painel](https://app.arpoflow.com.br/projects)
