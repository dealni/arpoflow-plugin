# ArpoFlow para Google Antigravity

Crie e edite sites e aplicativos TanStack Start na sua conta ArpoFlow. Você pode visualizar uma prévia privada, verificar o projeto e publicar a versão escolhida.

## Instalação

Extraia o ZIP do plugin e execute `agy plugin install ./arpoflow` no diretório que contém a pasta extraída. Use `agy plugin list` para conferir a instalação. No Antigravity, abra a configuração de servidores MCP do plugin ArpoFlow, inicie a autenticação e autorize o acesso à conta ArpoFlow pelo navegador.

Peça “Liste os meus projetos no ArpoFlow”. Em seguida, envie “Crie um projeto de teste chamado Agenda de oficinas, salve uma página com esse título e mostre a URL de prévia retornada pelo ArpoFlow, o ID do projeto, a versão e a validade da prévia. Mantenha o projeto como rascunho.” Aprove as ações separadamente quando o Antigravity solicitar.

Em outra conversa, informe o ID ou o nome do projeto e peça para ler a versão atual antes de editar. Depois, peça a prévia da nova versão salva. Abra o **Resumo** no painel para conferir o rascunho e a versão no ar. Em **Publicar**, você escolhe a versão desejada. Se precisar voltar à publicação anterior, use **Histórico → Publicações do site**. [Projetos no painel](https://app.arpoflow.com.br/projects)
